## Ответы о прежней работе и коде

1. Последний час работы прежнего чата завершился 08.10 около 22:16 МСК. Чат
   «Добавить текстуры и тиры механизмов» дошёл до вычислительных интерфейсов TecTech,
   затем продолжил аудит каталога и начал Boldarnator. В журнале сохранены прежние прогоны
   1866 native-сценариев, 4558 unit-тестов и 41 E2E; это исторические результаты,
   а не проверки текущего этапа. Последний заход прервался по лимиту. Старый `PLAN.md`
   в рабочем дереве отсутствовал, поэтому точный номер этапа прежней редакции не восстановлен.
2. Git не содержит временной границы 07.10 для прежних изменений: они были незакоммичены
   поверх `b9969eb` от 01.10. Показанный перед сохранением `git diff --stat` для
   `src/model/site`, `src/model/hatches`, `src/model/layout`, файлов упаковки,
   `src/ui/siteArrange.ts`, `src/ui/siteCommands.ts`, `src/ui/sitePipeline.ts` и
   `src/import/gtnhplanner` дал **24 файла, +971/−129 строк**. Неотслеживаемые файлы
   в этот вывод не входят; теперь они доступны в сохранённом коммите.
3. Итоговая сборка после «Выровнять» и «Оптимизировать» использует общий `createSiteBuilder`.
   После трассировки вызываются `validateHatchAccess`, `validateResourceHatches` и
   `validateAlternativeCounts`. Оптимизатор считает предупреждения при оценке кандидатов,
   однако может вернуть ошибочный исходный расклад. «Выровнять» не требует нулевых нарушений.
   Property-тест инварианта не добавлен на этапе 0.
4. `withDemand` повышает минимум люков до числа ресурсов для каждого контроллера;
   `assign` и `missing` повторяют весь список по `unitId`. `placeResourceHatches` тоже
   создаёт ресурсные слоты внутри цикла по машинам. Затем сортировка по числу кандидатов
   отдаёт первые места ограниченным ресурсным слотам, а лучший частичный результат
   выбирается по числу оставшихся слотов, без приоритета энергии и обслуживания.
   Проверка получает завышенные минимумы из `withDemand`, а цикл `resourceBindings`
   в `validateResourceHatches` требует каждый вход с ролью у каждой машины. Независимость
   проверки геометрии не исправляет ошибочную семантику группового спроса.
