## 2. Решения ведущего (технические, принятые)

- **Бюджет L1 — в операциях, не во времени** (счётчик извлечений из кучи): детерминирован, ключи `pipelineKeys` не меняются.
  Пороги: 8 млн на маршрут, 64 млн на `resolveRoutedLayout`. Прототип: 730 из 732 прогонов каталога побайтно не изменились,
  меняется только Nanochip (n=4: 125 с → ~7 с, 0 неподключённых; n=7: ~4 мин → ~12 с, 3 неподключённых).
- **Q3/Q4:** раздельные лимиты: ссылка 64 КБ; JSON плана 1 МиБ; JSON шаблона 2 МиБ. Лимиты только растут — всё старое
  читается. Ошибка «слишком велико для ссылки» — с кнопкой «Скачать JSON».
- **Q2 (D1):** автосохранение приостановлено, пока пользователь не выберет действие; явное открытие файла или ссылки снимает
  приостановку, только если резервная копия проверенно записана. Хранить не больше 3 копий на тип.
- **Q8:** таблица алиасов id и замена неизвестной группы шаблона заглушкой `placeholder` с меткой `Missing: <id>` — **без
  изменения формата** (поле `lostId` не добавляем, оригинал сохраняется в резервной копии). Тест-снимок всех id каталога.
- **Q5:** управляющие символы заменяются, количество ограничивается, ставки вне диапазона отбрасываются; счётчик
  `adjusted` в отчёте импорта.
- **A3:** правка шаблона отменяет идущий Arrange/Optimize (его результат и так был бы выброшен); уведомления
  «отменено/ошибка» вместо зависшего «Arranging…».
- **A6:** «Add to template» из машинного вида при не собранном шаблоне — оценка положения по состоянию шаблона.
- **L2:** при равенстве — лексикографически: меньше неподключённых → меньше видов с неподключёнными → меньше стоимость.
- **G1:** при выборе приоритет у непрозрачных попаданий; тусклая труба выбирается, только если за ней ничего нет.
