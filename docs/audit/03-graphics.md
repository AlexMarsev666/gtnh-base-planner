# 03 — Three.js, текстуры, память, производительность

Агент: `graphics-reviewer` (Sonnet), только Read/Grep/Glob. Прочитаны полностью `renderer.ts` (1259 строк), `controls.ts`,
`detailed.ts`, `simple.ts`, `materials.ts`, `Scene.svelte`, `model/scene.ts`, `model/site/siteScene.ts`, `build-atlas.mjs`,
`check-size.mjs`, `public/_headers`, `vite.config.ts`. Критических находок нет.

**Утечек не найдено:** геометрии, материалы и текстуры освобождаются при пересборке и уничтожении; все слушатели снимаются,
rAF отменяется, `ResizeObserver` отключается. Атлас на GPU не семплируется (каждая грань — свой 16×16 `DataTexture`), так что
«кровотечения» UV нет. CSP в `_headers` соответствует тому, что грузит код.

## Подтверждённые ошибки

### G1. Выбор объекта игнорирует прозрачность (тусклые трубы, X-ray) — Medium

- **Где:** `src/render/renderer.ts:1068-1093` (`pick`), `:1003-1019` (`startDrag`), `:792-829`, `:608-621`.
- **Доказательство:** тусклые трубы (`pipeDimMat`, 14 %) добавляются в `pipeBatches` (`:814`, `:829`) только с `netIds`, флаг
  `dim` теряется; `pick` берёт ближайшее пересечение по `[...batches, ...pipeBatches]` без проверки `dim`/X-ray. В X-ray корпуса
  (10 %) остаются в `batches`. **Проверено ведущим.**
- **Воспроизведение:** вид шаблона → выбрать ресурс (остальные сети тускнеют) → кликнуть группу за тусклой трубой →
  выбирается сеть, а не группа; перетаскивание не начинается. Машинный вид, X-ray → клик по хэтчу внутри стены выбирает
  передний корпус.
- **Исправление:** хранить `dim` в батче и пропускать тусклые батчи; в X-ray пропускать батчи корпусов.

### G2. Сбой загрузки атласа DETAILED проглатывается навсегда, а режим показан как DETAILED — Low–Medium

- **Где:** `src/render/detailed.ts:262-273`, `src/render/renderer.ts:1116-1145`.
- **Доказательство:** `loading ??= loadAtlas().then(ok, (err) => { console.warn(...) })` превращает ошибку в успех и
  запоминает промис; ветка повтора в `renderer.ts:1137` недостижима; грани рисуются плоскими цветами.
- **Воспроизведение:** заблокировать `/textures/atlas.png` (офлайн, 404) → включить DETAILED → плоские цвета до перезагрузки,
  переключатель показывает DETAILED, уведомления нет.
- **Исправление:** отклонять `load()` или сбрасывать `loading` при ошибке; показывать уведомление.
- Совпадает с находкой прошлого аудита (тесты и безопасность, №10).

## Риски (нужны измерения в браузере/GPU)

- **G3. Нет обработки потери WebGL-контекста — Medium.** `renderer.ts:280-288,420-428`; в `src` нет `webglcontextlost`/`restored`.
  Рендер по требованию: после восстановления контекста кадр никто не запрашивает → пустой холст до взаимодействия.
  Исправление: на `webglcontextrestored` вызвать `requestRender()`, на `lost` — уведомление.
- **G4. Каждое изменение сцены пересобирает всё, включая canvas-текстуры подписей — Medium.** `renderer.ts:1102-1114,918-932,
578-592,907-916,138-192`; `buildHatchMarkers` — вложенный цикл сети × хэтчи (`:769`). На шаблоне каждая правка даёт ≥2
  полные пересборки (группы, затем трубы). Исправление: кэш текстур подписей по `(text, swatch, small, dpr)`.
- **G5. Анимация стрелок потока — бесконечный цикл 60 Гц по всей сцене — Medium.** `renderer.ts:420-428,438-512`;
  `flowAnimation` по умолчанию `true` (`src/state/site.ts:25`). Каждый кадр — полный рендер (DPR до 2, MSAA), declutter со
  строкой `matrixWorld.elements.join(',')`, аллокации; нет учёта `prefers-reduced-motion`, нет ограничения FPS.
  Исправление: ~30 fps, `DynamicDrawUsage`, пауза при blur/reduced-motion.
- **G6. Атлас и манифест могут разойтись между деплоями — Low–Medium.** `detailed.ts:107-127`; прямоугольники тайлов в
  хэшированном JS, а `textures/atlas.png` без хэша (`_headers:14-15` кэширует навсегда только `/assets/*`). Старая вкладка
  после деплоя покажет не те текстуры. Исправление: хэш в URL атласа.
- **G7. `devicePixelRatio` фиксируется при создании — Low.** `renderer.ts:285`; масштаб страницы или перенос на другой монитор →
  размытие до перезагрузки.
- **G8. Порядок прозрачных объектов по началу координат батча — Low.** `detailed.ts:223-225`, `renderer.ts:616-619,334-342`.
- **G9. Контур перетаскивания остаётся смещённым при пустом перемещении — Low.** `renderer.ts:1035-1050,1154-1160`.
- **G10. Raycast линеен по числу экземпляров — Low.** `renderer.ts:1005-1008,1071-1074`.
- **G11. Изменение границ сцены сбрасывает зум и панораму — Low.** `renderer.ts:1107-1113,562-574`.
